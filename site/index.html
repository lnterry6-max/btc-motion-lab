CLEAR METHODOLOGY

Built to show the limits, not hide them.

01 /

Only completed candles

Fetch recent BTC/USD 5-minute price history, discard unfinished candles and retain missing periods instead of silently skipping them.

02 /

Actual historical ranges

Measure the signed 10th–90th percentile changes and typical absolute moves. Convert percentages to illustrative dollar equivalents at the last close.

03 /

Separated training & testing

Compare Ridge regression and gradient boosting on validation data, then measure results on a later untouched holdout with a gap for overlapping targets.

04 /

A baseline is mandatory

Show zero-movement baseline error and majority-direction baseline accuracy. If a model underperforms, the dashboard says so.

Coverage is limited to roughly the latest 60 days of 5-minute data from Yahoo Finance. Market regimes change; short samples and overlapping windows can make apparent patterns unstable. Data can be delayed or incomplete.
